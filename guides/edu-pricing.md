# Student & education pricing

Complete checkout on **official** vendor domains — not key resellers. Eligibility (school email, ID, age) is defined on each site.

| Vendor | What to look for | Official |
| --- | --- | --- |
| Ableton | Live Intro / Standard / Suite education | [ableton.com/en/education](https://www.ableton.com/en/education/) |
| Avid | Pro Tools student / teacher | [avid.com/education](https://www.avid.com/education) |
| Steinberg | Cubase / Nuendo education | [steinberg.net/education](https://www.steinberg.net/education/) |
| Image-Line | FL Studio terms on site | [image-line.com](https://www.image-line.com/) |
| Adobe | Creative Cloud student (Audition, etc.) | [adobe.com/creativecloud/buy/students.html](https://www.adobe.com/creativecloud/buy/students.html) |
| iZotope | Education store | [izotope.com/en/shop/education-pricing.html](https://www.izotope.com/en/shop/education-pricing.html) |
| PreSonus | Studio One education | [presonus.com/pages/students-teachers](https://www.presonus.com/pages/students-teachers) |
| Apple | Pro Apps bundle for education (where offered) | [apple.com/education](https://www.apple.com/education/) |
