## Common student use cases → start in ai-catalog

| Use case | Look for in ai-catalog |
| --- | --- |
| Text-to-speech / voiceover | ElevenLabs, OpenAI TTS, Azure Speech, Google Cloud TTS |
| Speech-to-text / captions | Whisper, AssemblyAI, Deepgram |
| Music generation | Suno, Udio (verify license for your project) |
| Stem separation / cleanup | LALAL.AI, Demucs (open models) |
| Local / private inference | Ollama + audio models, local Whisper builds |
