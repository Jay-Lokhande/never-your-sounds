# Samples, SFX & licensing

**Rule:** read the license **per file or pack** before you ship a game, video, or release.

## Libraries

| Library | Notes | Official |
| --- | --- | --- |
| Freesound | CC-licensed sounds; read each license | [freesound.org](https://freesound.org/) |
| OpenGameArt (audio) | Game assets; check per file | [opengameart.org](https://opengameart.org/) |
| BBC Sound Effects | Personal / educational terms on site | [sound-effects.bbcrewind.co.uk](https://sound-effects.bbcrewind.co.uk/) |
| YouTube Audio Library | For YouTube; read usage rules | [studio.youtube.com](https://studio.youtube.com/) |
| Pixabay Audio | Check license per track | [pixabay.com/music](https://pixabay.com/music/) |
| Free Music Archive | Various CC licenses | [freemusicarchive.org](https://freemusicarchive.org/) |
| Incompetech (Kevin MacLeod) | CC BY; attribution required | [incompetech.com](https://incompetech.com/) |
| Sonniss GDC bundles | Free SFX packs; read each bundle license | [sonniss.com/gameaudiogdc](https://sonniss.com/gameaudiogdc) |
| ZapSplat | Free tier + paid; read license tier | [zapsplat.com](https://www.zapsplat.com/) |

## Habit checklist

1. Screenshot or PDF the license page when you download.  
2. Keep attribution text in your game credits or video description when required.  
3. “Royalty-free” on a random blog is not a license — use the **official** library site above.
