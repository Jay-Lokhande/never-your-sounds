# License checklist — before you ship

Print or duplicate this list for each project (game jam, YouTube video, Bandcamp single, school assignment).

Back: [samples-and-licensing guide](../guides/samples-and-licensing.md) · [Home on Pages](https://jay-lokhande.github.io/sound-student/)

---

## Project: _______________  Date: _______________

### Samples & music

- [ ] Every sample/track has a **saved license** (screenshot or PDF) from the **official** library site  
- [ ] Attribution text written for credits / description (if CC or required)  
- [ ] No “royalty-free” packs from random marketplaces without license URL  
- [ ] AI-generated music/voice: read **vendor terms** for commercial use ([ai-audio guide](../guides/ai-audio.md))

### Software

- [ ] DAW and plugins installed from **vendor domains** in [production guide](../guides/production.md)  
- [ ] Student licenses purchased on **official** edu stores ([edu-pricing](../guides/edu-pricing.md))

### Video & podcast

- [ ] Music cleared for **this platform** (YouTube ≠ TikTok ≠ film festival)  
- [ ] Captions or transcript planned ([accessibility](../guides/accessibility.md))

### Game

- [ ] SFX license allows **distribution** (check OpenGameArt / Freesound per file)  
- [ ] Middleware (FMOD/Wwise) use matches **vendor FAQ** for your release type  

### Release

- [ ] DistroKid / Bandcamp / itch terms read on **official** site  
- [ ] No uncleared cover songs or trademarked stings  

---

**Red flags:** Telegram “full DAW,” crypto-only plugins, no license page → [audio-scams.md](audio-scams.md)
